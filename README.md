# robot-emil
Robot Emil – Grid Robot Simulator (Python)
Načítanie mapy zo súboru (trojice: znak, riadok, stĺpec) a vytvorenie hracej plochy podľa max rozmerov

Simulácia pohybu robota v štyroch smeroch (v/j/z/s) s pohybom “na doraz” po prekážku alebo okraj

Zber predmetov počas prejdenej trasy + evidencia navštívených políčok a poradia zberu

Výstup: počet krokov a množina predmetov zozbieraných jedným behom príkazov, plus historický zoznam zberu
